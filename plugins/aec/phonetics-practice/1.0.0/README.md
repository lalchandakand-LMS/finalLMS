# Phonetics & Pronunciation Practice
- Admin-curated English words and sentences with Bangla meanings.
- Separate British English (en-GB) and American English (en-US) IPA and optional private audio uploads.
- Student exact-match lookup, browser text-to-speech fallback and optional browser speech-recognition similarity feedback.
- Shared entries for all students or course-bound entries restricted to active/completed enrollments, whether free or paid.
- Arbitrary learner text is not sent to a third-party translation service. Translations are managed in the LMS library.
Install the signed ZIP through Admin → Plugin Manager, activate it and grant phonetics.manage / phonetics.practice. Git source is not an installed or activated release; trusted release signing is required.
